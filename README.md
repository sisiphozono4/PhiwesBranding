# Phiwe's Branding

A beginner C# console application created for a custom branding business.

## About the Project

Phiwe's Branding is a console-based ordering program that guides a customer
through the available branding services and product options.

The program allows the user to select a service, choose a product, and enter
the required quantity. It then provides the customer with order confirmation
instructions and contact information.

## Services

The program currently includes:

- Boards
- Cups
- Stickers

## Features

- Branded welcome screen
- Service selection
- Product selection
- Quantity input
- Order confirmation instructions
- Contact and business information

## Technologies Used

- C#
- .NET
- Console Application

## C# Concepts Practised

- Variables
- Integer data types
- User input
- `Console.WriteLine()` and `Console.Write()`
- `Console.ReadLine()`
- Type conversion using `Convert.ToInt32()`
- `if` and `else if` statements
- Basic program flow
- String escape sequences
